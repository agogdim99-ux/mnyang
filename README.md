# 멍냥 초원

## ▶ [여기를 눌러 게임하기](https://agogdim99-ux.github.io/mnyang/)

**게임 주소:** https://agogdim99-ux.github.io/mnyang/

강아지나 고양이를 골라 아침부터 밤까지 달려서 집에 가는 힐링 점프 게임이에요.

- 조작: 폰은 화면 터치, 컴퓨터는 스페이스바로 점프 (두 번 누르면 2단 점프)
- 모드: 쉬운 / 보통 / 하드
- 간식 1개를 먹으면 하트 반 개 회복, 장애물에 부딪히면 하트 1개 감소
- 아침(나뭇잎·벌레) → 오후(빗방울) → 밤(별똥별) → 집에 도착하면 주인 품에 안기는 엔딩
